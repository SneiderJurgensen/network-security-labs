# Análisis de Tráfico con Wireshark

Laboratorio práctico de captura y análisis de tráfico de red utilizando Wireshark.

## Objetivo

Analizar protocolos de red, identificar patrones de tráfico y detectar posibles anomalías o vulnerabilidades a nivel de red.

## Contenido

- `report-es.pdf` → Informe completo en español
- `report-en.pdf` → Informe en inglés (opcional)
- `captures/` → Archivos `.pcap` generados durante el laboratorio
- `screenshots/` → Capturas de pantalla del análisis
- `notes/` → Notas adicionales y observaciones

## Herramientas

- Wireshark
- tcpdump (opcional)
- Nmap (para generación de tráfico controlado)

## Cómo usar

1. Abre los archivos `.pcap` con Wireshark.
2. Revisa el informe para entender el análisis realizado.
3. Observa las capturas de pantalla como referencia visual.
